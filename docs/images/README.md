# App screenshots

These are unmodified PNG screen captures from the installed BDK Audio **0.7.2**
Android application on a **Redmagic NX809J**, captured on **2026-10-20**.
They show the native Flutter application, not the HTML design prototype.

| Image | Screen |
|---|---|
| [sound.png](sound.png) | Sound, current configuration and illustrated presets |
| [light.png](light.png) | Light, diffused Plasma preview and brightness control |
| [audio-quality.png](audio-quality.png) | Observed LHDC V5 configuration and preference entry |

Only navigation, scrolling and screen capture were used. No speaker settings or
codec preferences were changed to prepare these images. Device status-bar icons
and the phone's floating overlay are retained as part of the original captures.
The configuration shown is an observation on this phone, not a promise of that
format on other devices. Bitrate values represent configured targets.

The accompanying [SHA256 manifest](screenshots.json) records the exact published
image bytes and dimensions. Existing third-party app icons visible in the OS
status bar remain the property of their respective owners.
